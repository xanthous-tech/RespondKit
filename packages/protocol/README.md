# @respondkit/protocol

Versioned schemas, identifiers, and TypeScript types shared by RespondKit customer clients.

```sh
pnpm add @respondkit/protocol
```

Most applications should install [`@respondkit/react`](https://www.npmjs.com/package/@respondkit/react) instead. Use this package directly when implementing a custom customer client or integrating with the RespondKit HTTP API.

The current protocol version is exported as `API_VERSION`.
