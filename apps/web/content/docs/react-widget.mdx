`RespondKitWidget` is the public React entrypoint. It owns session bootstrap, thread creation, message polling, optimistic sends, retry state, and the visible chat interface.

## Props

| Prop            | Type                    | Description                                                         |
| --------------- | ----------------------- | ------------------------------------------------------------------- |
| `apiBaseUrl`    | `string`                | RespondKit API origin.                                              |
| `context`       | `RespondKitContext`     | Product and customer context for this conversation.                 |
| `title`         | `string`                | Header text shown in the open widget.                               |
| `accentColor`   | `RespondKitAccentColor` | Tailwind palette family used by the launcher and customer messages. |
| `initiallyOpen` | `boolean`               | Opens the widget on its first render.                               |
| `fetch`         | `typeof fetch`          | Optional fetch implementation for hosts that need to supply one.    |

## Accent colors

The widget supports the standard Tailwind color families, including `lime`, `indigo`, `rose`, `slate`, and `neutral`.

```tsx
<RespondKitWidget
  apiBaseUrl="https://api.respondkit.dev"
  accentColor="lime"
  context={{ inboxId: "inbox_example", userId: currentUser.id }}
/>
```

## Customer identity

Pass your stable internal ID whenever possible. Add `getIdentityToken`, an async callback fetching a short-lived HS256 assertion from your authenticated backend, to link anonymous conversations and recover account history across browsers. Pass `identityPending` while authentication is loading. Raw user IDs and PostHog IDs remain advisory and cannot grant history access.

The widget preserves browser identity through login, rotates it on logout or account switching, and offers a conversation selector when account history contains multiple threads. `posthogSessionId` is accepted alongside `posthogDistinctId` for analytics correlation. See the repository’s [identity setup guide](https://github.com/xanthous-tech/RespondKit/blob/main/docs/architecture/customer-identity.md) for the JWT contract and rollout order.
